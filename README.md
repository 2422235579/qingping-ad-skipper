# 清屏 - 安卓开屏广告拦截器

## 一、实现原理

核心技术是 **AccessibilityService（无障碍服务）**，和"李跳跳""一指禅"等同款方案。

流程：
1. 无障碍服务监听所有APP的窗口变化事件
2. 当检测到某个APP窗口刷新（开屏广告弹出），延迟300ms等控件渲染
3. 遍历控件树，找文字为"跳过""跳过广告"或特定resourceId的按钮
4. 自动模拟点击该按钮
5. 把拦截记录写入Room数据库，按包名聚合统计

---

## 二、需要哪些权限

| 权限 | 作用 | 能否静默获取 |
|------|------|-------------|
| **无障碍服务** | 核心能力：读取其他APP界面控件树、模拟点击 | ❌ 必须用户手动在设置里开启 |
| **使用情况访问权** | 判断当前前台是哪个APP（部分场景辅助判断） | ❌ 必须用户手动授权 |
| **RECEIVE_BOOT_COMPLETED** | 开机后启动保活服务 | ✅ 普通权限，安装即获得 |
| **FOREGROUND_SERVICE** | 启动前台保活服务 | ✅ 普通权限 |
| **POST_NOTIFICATIONS** (Android 13+) | 前台服务需要发通知才能保活 | ❌ Android 13+需用户同意 |
| **SYSTEM_ALERT_WINDOW** | 悬浮窗（~~本方案未用，预留~~ **已移除**） | — |
| **忽略电池优化** | 加入系统白名单，防止被杀 | ❌ 需用户手动授权 |

## 三、能实现什么 / 不能实现什么

### ✅ 可以实现

1. **自动点击开屏广告的"跳过"按钮**
   - 主流广告SDK（优量汇、穿山甲、百度广告等）的跳过按钮都能识别
   - 通过文字匹配 + resourceId匹配双通道，覆盖率较高
   - 按APP包名统计拦截次数，本地Room数据库存储

2. **减少误触跳转概率**
   - 广告弹窗一出现就自动关闭，用户手指还没碰到就被关掉了

3. **开机后自动启动保活服务**
   - BootReceiver监听 BOOT_COMPLETED，启动前台服务
   - 前台服务发常驻通知，降低被系统杀死的概率

4. **在软件内查看统计**
   - 总拦截数、今日拦截数、按APP分组的拦截明细

### ❌ 受系统限制，做不到

1. **无法真正"阻止"跳转行为本身**
   - 安卓没有API允许一个第三方APP阻止另一个APP启动Activity
   - 广告误触跳转是"点击广告 → 打开应用商店/网页"，这个跳转一旦触发，无障碍服务拦不住
   - 能做的只是**提前关掉广告弹窗**，减少误触机会
   - 要真正拦截跳转，需要VPN（VpnService）在网络层切断，或者用设备管理员/DevicePolicyManager，这些都需要特殊条件

2. **无法做到100%自动重启无障碍服务**
   - 安卓系统安全设计：无障碍服务一旦被用户手动关闭或系统重启后，**必须用户重新去设置里手动开启**
   - BootReceiver只能启动保活Service，不能重新绑定无障碍服务
   - 部分国产ROM（小米、华为、OPPO、Vivo）在开机后会自动恢复之前开启的无障碍服务，但这不保证，也不是所有机型都支持

3. **国产ROM后台杀进程问题**
   - 小米/华为/OPPO/Vivo/魅族都有激进的后台清理
   - 即使加了电池优化白名单，系统仍然可能在内存紧张时杀死服务
   - 这就是为什么需要前台服务常驻通知——通知在，系统才不太敢杀
   - 终极方案：引导用户在系统设置里手动把本APP加入"自启动管理"白名单

4. **无法拦截视频信息流中的广告**
   - 无障碍服务只能识别有文字按钮（"跳过"）的开屏广告
   - 抖音/B站信息流里的"广告"标签没有跳过按钮，拦截不了
   - 横幅广告、激励视频广告等也不在拦截范围

5. **深色/变体跳过按钮识别不全**
   - 有些APP的跳过按钮是图片不是文字，或者文字被藏在自定义View里
   - resourceId会随广告SDK版本变化，需要持续更新匹配规则

## 四、保活策略说明

本方案使用了三层保活：

1. **前台服务（startForeground）**：发一个低优先级常驻通知
2. **START_STICKY**：服务被杀死后系统尝试重建
3. **BootReceiver**：开机后重新拉起服务
4. **电池优化白名单引导**：让用户手动把APP加入白名单

但要清楚：**在安卓上，没有任何第三方APP能100%保活**。国产ROM的后台管理是系统级的，用户必须手动配合：
- 允许自启动
- 关闭后台优化
- 锁定最近任务卡片（下拉加锁）

## 六、编译方法

用 Android Studio Hedgehog (2023.1) 或更高版本打开 `qingping/` 目录，Gradle sync 后直接 Build APK 即可。

minSdk 26 (Android 8.0)，targetSdk 34 (Android 14)。

---

## 七、用户首次使用步骤

1. 安装后打开APP
2. 点"去开启无障碍服务"→ 在系统设置里找到"清屏"→ 开启
3. 点"授予使用情况访问权限"→ 找到清屏 → 允许
4. 点"加入电池优化白名单"→ 允许
5. 点"授予通知权限"→ 允许（Android 13+）
6. （国产ROM额外操作）在系统设置里找到"自启动管理"→ 允许清屏自启动
7. 打开任意有开屏广告的APP，广告会被自动跳过
8. 回到清屏APP查看拦截统计
